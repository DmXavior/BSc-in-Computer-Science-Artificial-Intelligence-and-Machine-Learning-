## Weather Analysis Toolkit ##

A command line interface application for visualising and predicting weather data.

## Installation and Execution ##

1. Make sure to navigate to the right project folder i.e., cd src
2. Compile using the following - (please use c++20): 
    g++ -o weather_app candlestickData.cpp filterData.cpp main.cpp menu.cpp plotData.cpp predictData.cpp weatherManager.cpp -std=c++20
3. Execute app: ./weather_app
