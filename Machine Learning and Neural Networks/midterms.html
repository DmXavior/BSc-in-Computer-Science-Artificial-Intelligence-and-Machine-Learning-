CM3015 - ML&NN: MIDTERMS¶

Aim¶

The main focus of this project is to compare two ML algorithms, k-Nearest Neighbours (kNN) vs. Decision Trees, in their abilities to classify accurately if a mushrooom is edible or poisonous based on its physical characteristics.

Dataset Overview¶

The dataset is a csv file of Mushroom Classification, distinguishing hypothetical samples of 23 species of gilled mushrooms in the Agaricus and Lepiota Family Mushroom drawn from The Audubon Society Field Guide to North American Mushrooms (1981). The mushrooms are identified as edible or poisonous based on their physical attributes.

The data features 22 categorical attributes, for example:

  • Cap Shape: bell, conical, flat, etc.
  • Odor: foul, anise, almond, etc.
  • Gill Color: brown, buff, black, etc.
  • Spore Print Color: brown buff, black, etc.

The mushrooms are labelled:

  • e (Edible)
  • p (Poisonous)

import numpy as np
from collections import Counter
import matplotlib.pyplot as plt

# Function to calculate Euclidean distance
def euclidean_distance(x1, x2):
    return np.sqrt(np.sum((x1 - x2) ** 2))

# kNN Algorithm
class KNN:
    def __init__(self, k=81):
        # Ensure k is odd
        if k % 2 == 0:
            raise ValueError("k must be an odd number.")
        self.k = k

    def fit(self, X, y):
        # Input validation
        if len(X) != len(y):
            raise ValueError("The number of samples in X and y must be the same.")
        self.X_train = np.array(X)
        self.y_train = np.array(y)

    def predict(self, X):
        X = np.array(X)
        predictions = [self._predict(x) for x in X]
        return np.array(predictions)

    def _predict(self, x):
        # Compute distances
        distances = [euclidean_distance(x, x_train) for x_train in self.X_train]
        # Get indices of the k-nearest neighbors
        k_indices = np.argsort(distances)[:self.k]
        # Get the classes of the k-nearest neighbors
        k_neighbor_labels = [self.y_train[i] for i in k_indices]
        # Determine the majority class
        most_common = Counter(k_neighbor_labels).most_common(1)
        return most_common[0][0]

# Set a single value for k
k = 85  # Adjust this value as needed

# Instantiate and fit the kNN classifier
knn = KNN(k=k)
knn.fit(X_train, y_train)

# Predict on the test set
y_pred = knn.predict(X_test)

# Evaluate accuracy
accuracy = np.sum(y_pred == y_test.values) / len(y_test)
print(f"Accuracy for k={k}: {accuracy:.2f}")

# Plot actual vs predicted
plt.figure(figsize=(10, 6))
plt.scatter(range(len(y_test)), y_test, color='blue', alpha=0.6, label='Actual')
plt.scatter(range(len(y_test)), y_pred, color='red', alpha=0.6, label='Predicted')
plt.title(f'kNN Predictions vs Actual Values (k={k})')
plt.xlabel('Sample Index')
plt.ylabel('Class')
plt.legend()
plt.show()

Comparison of kNN vs. Decision Tree results¶

Although both kNN and Decision Tree algorithms are used for classification tasks, they operate in fundamentally different ways.

kNN does not create rules or ask questions. Instead, it identifies the closest examples in the training data to make predictions. When classifying a new mushroom, kNN calculates the similarity or distance between the new mushroom and every other mushroom in the training set. It then identifies the k nearest neighbors. If the majority of these neighbors are poisonous, the algorithm predicts the new mushroom is poisonous; if the majority are edible, it predicts the mushroom is edible.

In contrast, Decision Trees take a rule-based approach. Rather than comparing the new mushroom to surrounding examples, the Decision Tree asks a series of binary yes-or-no questions to classify it. Depending on the answer to each question, the algorithm moves down one branch of the tree until it reaches a final decision: edible or poisonous. The Decision Tree learns these “rules” from the training data and applies them during prediction. Unlike kNN, which relies directly on the training data, the Decision Tree does not need to reference the training set once it has built the tree.

Comparing these two methods, Decision Tree is generally more efficient for larger datasets. Once trained, it uses its learned rules to make predictions very quickly, as it does not rely on computing distances for each new data point. kNN, on the other hand, can struggle with large datasets, as its prediction process requires calculating distances for every test point against all training points, making it slower and potentially less accurate in such cases.

In conclusion, the Decision Tree outperformed kNN in this case, achieving perfect accuracy (100%) compared to kNN’s 95%. This difference is likely due to the size and structure of the dataset, which allowed the Decision Tree to effectively learn and apply clear classification rules.
